    Understanding the tests

    When to use each, formulas, and practical guidance

    01

    Sign Test

    Simplest nonparametric test. Uses only direction (+/-) vs hypothesized median. No distributional assumptions, but low power.

    p = 2·P(Bin(n,0.5) ≤ k)
    Best when: Data is ordinal or symmetry is doubtful
    02

    Wilcoxon Signed-Rank

    More powerful than Sign Test by ranking absolute differences. Requires symmetric distribution of differences.

    W = min(W⁺,W⁻), z = (W-μ+½)/σ
    Best when: Paired data or one-sample with symmetry
    03

    Kruskal-Wallis H

    Nonparametric ANOVA. Compares 3+ independent groups via ranks. Follow with Dunn post-hoc if significant.

    H = 12/[N(N+1)]·ΣRᵢ²/nᵢ -3(N+1)
    Best when: 3+ groups, non-normal or ordinal outcome
    ✦

    How to choose?

    One sample? Sign if no symmetry, Wilcoxon if symmetric.
    3+ independent? Kruskal-Wallis.

    Check normality with Shapiro, but prefer nonparametric for ordinal / skewed
